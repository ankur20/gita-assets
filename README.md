# Gita Flow Artwork Assets

Public asset repository for [Bhagavad Gita Flow](https://github.com/ankur20/gita-assets).

This repository hosts high-resolution, 16:9 wide cinematic narrative artwork for verses of the Srimad Bhagavad Gita. Assets are served globally via the [jsDelivr Open Source CDN](https://www.jsdelivr.com/).

## CDN URL Pattern
```
https://cdn.jsdelivr.net/gh/ankur20/gita-assets@main/images/ch{chapter_2_digits}/art_bg_{chapter}_{verse}.webp
```

## Structure
```
images/
  ch01/
    art_bg_1_1.webp
    ...
  ch02/
    art_bg_2_1.webp
    ...
```
